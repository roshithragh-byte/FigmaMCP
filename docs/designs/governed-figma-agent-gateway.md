## Problem Statement
Autonomous coding agents (Claude Code, Devin, custom PR review bots) operating in headless environments (GitHub Actions, container sandboxes, Cloud Run) cannot use Figma's official remote MCP server due to mandatory interactive browser OAuth and allowlisted client constraints. Consequently, engineering teams either revert to manual developer laptop workflows or duct-tape shared Personal Access Tokens (PATs) into CI secrets, triggering InfoSec exposure, severe 429 rate limits, and massive LLM context blowouts on raw node JSON trees.

## Target User & Narrowest Wedge
- **Buyer**: Staff Platform Engineer / Head of Developer Experience at mid-to-large product companies.
- **Success/Failure Metric**: Promoted for accelerating engineering AI velocity; fired for security incidents or leaked tokens.
- **Deployment Topology**: Deployed as a centralized, authenticated Cloud Run service with `--max-instances=1` (to guarantee cache coherence and prevent process fragmentation) and IAM authentication. Headless CI runners connect via GitHub Actions OIDC (Workload Identity Federation) generating an authenticated Google ID token.

## Hardened Architecture & Technical Specifications

### 1. Security & Authorization (Secure by Default)
- **Read-Only Default**: `FIGMA_READ_ONLY: bool = True` (default in `config.py`). Mutating calls (`post_file_comment`) fail closed with structured `403 Forbidden` unless explicitly overridden.
- **File Key Allowlist**: `FIGMA_ALLOWED_FILE_KEYS: list[str] | None` in `config.py` (parsed from comma-separated env var). If set, any tool call targeting an unlisted file is immediately rejected with `403 Forbidden: File key not in allowed list`, preventing broad tenant exfiltration using a shared token.
- **Credential Redaction**: `_sanitize_text` intercepts all error strings and logs to scrub `FIGMA_ACCESS_TOKEN`.

### 2. Backward-Compatible AST Pruning (`compact_figma_node`)
- **Default Contract**: `compact: bool = False` (default) preserves 100% backward compatibility for existing MCP tools.
- **Opt-In Optimization**: Passing `compact=True` invokes the pruning transformer:
  - **Preserved Whitelist**: `id`, `name`, `type`, `visible`, `children`, `characters`, `componentId`, `styles`, `layoutMode`, `primaryAxisAlignItems`, `counterAxisAlignItems`, `padding*`, `itemSpacing`, `width`, `height`.
  - **Stripped Blacklist**: `vectorData`, `vectorNetwork`, `strokeGeometry`, `fillGeometry`, absolute transform matrices (`relativeTransform`), prototype interactions/transitions, and detailed export settings.
  - **Resilience**: Schema errors or missing attributes degrade gracefully to returning the raw node dictionary.

### 3. Rate-Limit Shield, In-Memory TTL Cache & SingleFlight
- **TTL**: Configurable via `FIGMA_CACHE_TTL_SECONDS` (default: 300 seconds).
- **Eviction**: In-memory LRU capped at `maxsize=500` entries.
- **SingleFlight Deduplication**: Async lock per cache key ensures that multiple concurrent CI runs requesting the same uncached frame coalesce into a single upstream Figma API call, completely eliminating thundering-herd 429s.
- **Bypass & Negative Caching**: `force_refresh: bool = False` argument allows callers to bypass cache on demand. HTTP 4xx/5xx/429 errors are never cached.

### 4. CI/CD Integration & GitHub Actions Workflow Template
- Located at `.github/workflows/figma-mcp-agent.yml` using `workflow_call`.
- Authenticates against Cloud Run using `google-github-actions/auth@v2` via Workload Identity Federation (WIF).
- Issues an authenticated identity token passed in the `Authorization: Bearer <ID_TOKEN>` header to the Cloud Run `/mcp` endpoint.
